# Trapdoor Dash 2

Part 2 of Trapdoor Dash — 10 brand-new harder levels.

## What's new

- **10 new levels** (different from Part 1), progressively harder
- **Chasers** — flying devils that hunt you down once triggered
- **Saws** — spinning blades moving along paths
- **Fake doors** — they look like the exit... they are not. Trust nothing.
- **Sound** — jump, death, win, warnings (Web Audio API, no files). Mute button in HUD.
- **Gloria** — new playable character
- Level Devil vibes: hidden pop-up spikes, falling spikes, crumbling & fake platforms

## Play

Open `index.html` or deploy to any static host (Vercel-ready).

Controls: Arrow keys / WASD / Space to jump. Touch buttons on mobile.
